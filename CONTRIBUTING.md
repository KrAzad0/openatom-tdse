# Contributing

Report reproducible bugs through GitHub Issues. Include Python/dependency versions, parameters, expected behavior, and a minimal example. For scientific changes cite the method, describe units and assumptions, and include analytic comparisons or convergence tests.

Fork, create a branch, install with `python -m pip install -e ".[dev]"`, run `python -m pytest`, and open a pull request explaining the change and limitations. Do not commit credentials or unlicensed datasets. Treat contributors respectfully. The maintainer reviews scientific correctness and tests before merging.
